01

PS4 package

This development profile targets PS4 and builds a Stremio-only GMCA package. Download the artifact named GMCA-PS4-Stremio-only from a successful run of the PS4 Stremio-only workflow. Each artifact includes a SHA-256 checksum.

Package identity: title ID GMCA00000, PS4 revision 00.82. The in-app updater verifies the package, saves it to /data/pkg, and prompts for manual installation in GoldHEN Package Installer.
02

Connect Stremio

The PS4 build opens the Stremio connection flow. Sign in with the account that has your desired catalogues and add-ons configured. Available streams depend on those add-ons and their sources.

04

Linux test bench

Linux exists only to test behavior shared with the PS4 build. It is not a supported delivery target and cannot validate PS4 input, graphics, playback, or package behavior. Select it explicitly and keep compilation to two jobs:

cmake -S . -B build-linux -DGMCA_LINUX_TEST_BENCH=ON -DCMAKE_BUILD_TYPE=Debug
cmake --build build-linux --parallel 2
05

FAQ

What is this development profile?

This branch specializes GMCA for PS4 and Stremio. The repository and changelog preserve the project's earlier platforms and backends.

Does the Linux build replace PS4 testing?

No. Linux is a shared-behavior test bench. Validate PS4-specific behavior with the PS4 package and device.

Where do I report a bug?

On the GitHub issue tracker. Include the PS4 model, Stremio add-ons involved, what you did, and what happened.
