03 PS4 Stremio profile

Built for the controller

Native C++ interface, controller navigation, Stremio catalogues, and mpv playback on PS4.

Native PS4 app

GMCA is built as a native PS4 package with Borealis and mpv.

Gamepad navigation

Every screen is laid out for a stick and four buttons. A confirms, B goes back, everywhere.

mpv playback

Video playback runs through mpv. Validate PS4-specific media behavior on the console.

Stremio library

Sign in with your Stremio account to see its synced library and configured catalogues.

Controller controls

Navigate and control playback with the PS4 pad. See the playback table in the guide.

Stremio styling

The current PS4 profile presents Stremio as its connection source.

Verified update package

The updater checks the rolling manifest and package hash, then leaves the package for manual installation.

Linux test bench

Linux is an explicit shared-behavior test bench only; keep local compilation at two jobs.
